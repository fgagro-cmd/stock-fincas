# Stock Fincas

App de stock, entradas y salidas de las fincas propias (PWA para Android, funciona sin conexión).

Publicar en GitHub Pages: crear un repositorio nuevo (por ejemplo `stock-fincas`), subir todos estos ficheros
a la raíz, y en Settings → Pages elegir la rama `main` y la carpeta `/ (root)`.
Después abrir la dirección en Chrome del móvil → menú ⋮ → «Instalar aplicación».

Al cambiar cualquier fichero, sube `VERSION` en `sw.js` para que los móviles recojan la nueva versión.
